# 🔐 Cifra de César — Criptografia

## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento de uma aplicação web para demonstrar, de forma prática e interativa, o funcionamento da **Cifra de César**, uma técnica clássica de criptografia baseada no deslocamento das letras do alfabeto.

O usuário pode informar um texto e escolher a quantidade de posições que cada letra deverá ser deslocada. O sistema então apresenta o texto cifrado.

Além da cifração, o projeto também possui uma função de **decifração**, permitindo retornar o texto ao seu formato original utilizando o mesmo deslocamento.

## 🎯 Objetivo

O objetivo da atividade é compreender, de maneira prática, alguns dos conceitos relacionados aos **princípios de criptografia e cifração**, utilizando JavaScript para implementar o algoritmo da Cifra de César.

O projeto também busca desenvolver conhecimentos de:

## 🔐 Como funciona a Cifra de César?

A Cifra de César funciona deslocando cada letra do texto uma determinada quantidade de posições no alfabeto.

Por exemplo, utilizando um deslocamento de **3 posições**:

```text
A → D
B → E
C → F
D → G
```

Assim, o texto:

```text
OLA
```

com deslocamento 3 se torna:

```text
ROD
```

Para decifrar, o processo é invertido:

```text
R → O
O → L
D → A
```

Resultado:

```text
OLA
```
